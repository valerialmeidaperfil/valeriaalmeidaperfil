Preciso criar um perfil profissional no GitHub com as seguintes características:

**Público-alvo:** Estudantes do Ensino Fundamental 2 (11 a 14 anos)
**Estilo visual:** Frutiger Aero (cores vibrantes, gradientes suaves, elementos com brilho/transparência, ícones divertidos, fundos com natureza ou céu, botões arredondados, sensação de frescor e tecnologia amigável)

**Conteúdo obrigatório:**
- Apresentação pessoal (nome e série escolar)
- Tecnologias que estou aprendendo (HTML, CSS, JavaScript, Scratch e GitHub)
- Objetivos de aprendizado
- Chamada para contato

**Tom de voz:** 
- Motivador e inspirador para jovens
- Linguagem simples e acessível
- Uso de emojis relacionados a tecnologia e natureza (🌱💻🚀☀️)
- Frases curtas e diretas
- Incluir "badges" ou etiquetas visuais das tecnologias

**Elementos visuais desejados:**
- Cabeçalho com gradiente azul/verde
- Avatar ou ilustração no estilo Frutiger (opcional)
- Cards ou blocos com fundo translúcido
- Ícones animados ou com brilho (representação em texto)
- Divisórias com elementos naturais (🍃☁️)

**Exemplo de estrutura:**
1. Título principal com saudação
2. Breve apresentação pessoal
3. Tecnologias que estou estudando (com ícones)
4. Projetos ou metas (se houver)
5. Seção de contato (com badges de redes sociais)

O perfil deve ser acolhedor, fazer o visitante se sentir parte de uma comunidade de aprendizado e transmitir entusiasmo pela programação.
